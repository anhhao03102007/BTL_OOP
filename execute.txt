[ JS UI / FRONTEND ]
        │
        │ 1. Gửi Payload JSON (await window.authBridge.login(payload))
        ▼
[ BRIDGE LAYER ] (AuthBridge / Thin Controller)
        │
        │ 2. Unpack JSON ──► Nạp dữ liệu vào DTO (LoginRequest)
        │ 3. Gọi m_loginService.login(dto)
        ▼
[ SERVICE LAYER ] (LoginService / Orchestrator)
        │
        │ 4. Yêu cầu Repository nạp dữ liệu từ DB
        ▼
[ REPOSITORY LAYER ] (UserRepository)
        │
        │ 5. Truy vấn TursoDB ──► Bóc tách Record thô ──► Khởi tạo Model
        ▼
[ DOMAIN MODEL ] (UserModel / AccountModel)
        │
        │ 6. Thực thi Logic Nghiệp vụ & Phân quyền trên RAM
        │    - Kiểm tra Quyền thao tác (hasPermission)
        │    - Kiểm tra Trạng thái & Điều kiện (canWithdraw, verifyPassword)
        │    - Thay đổi trạng thái nội bộ Model (withdraw, deposit, setStatus)
        ▼
[ REPOSITORY LAYER ] (Save back)
        │
        │ 7. Nhận Model đã được kiểm tra & sửa đổi hợp lệ
        │ 8. Thực thi SQL (UPDATE / INSERT) xuống TursoDB
        ▼
[ SERVICE LAYER ]
        │
        │ 9. Nhận trạng thái thành công ──► Đóng gói Result Struct (LoginResult)
        ▼
[ BRIDGE LAYER ]
        │
        │ 10. Chuyển Result Struct ──► Đóng gói JSON Response
        │ 11. (Tùy chọn) Emit Signal cập nhật UI nếu cần
        ▼
[ JS UI / FRONTEND ] (Nhận JSON Promise & Render Giao diện)
